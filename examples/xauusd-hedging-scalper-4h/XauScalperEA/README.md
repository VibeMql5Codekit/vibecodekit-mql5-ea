# scalping / hedging

EA scaffold generated by **vibecodekit-mql5-ea**.

## Quick start

```bash
mql5-build --preset scalping --stack hedging --name MyEA --output ./output
mql5-lint output/MyEA/MyEA.mq5
```

## Includes

- `CPipNormalizer.mqh` — cross-broker pip normalization
- `CRiskGuard.mqh` — daily-loss + max-positions guard

## Files

- `XauScalperEA.mq5` — main EA template (name replaced at build time)
- `Sets/default.set` — default optimization parameters
